## 1. Прогноз цены подержанных автомобилей
**Файл:** `task1.ipynb`

Регрессия для предсказания цены б/у автомобиля по его характеристикам (бренд, год, пробег, тип топлива, коробка передач, наличие ДТП, чистота титула).

- Очистка и кодирование признаков (One-Hot Encoding, StandardScaler)
- Сравнение `LinearRegression`, `Lasso`, `Ridge`
- Подбор гиперпараметров через `GridSearchCV`

**Результат:** лучшая модель — Ridge (alpha=1000), **R² ≈ 0.458** на тесте (против 0.41 у базовой линейной регрессии).

---

## 2. Сжатие изображений кластеризацией
**Файл:** `4task1.ipynb`

Пиксели изображения рассматриваются как точки в цветовом пространстве RGB и кластеризуются, чтобы уменьшить количество уникальных цветов и вес файла.

- Алгоритмы: `KMeans` (3 кластера/цвета) и `DBSCAN`
- Применено к двум изображениям (`bird_small.png`, `nn.jpg`)

**Результат:** сжатие изображений в **1.5–11.4 раза** по весу файла в зависимости от изображения и алгоритма.

---

## 3. Кластеризация стран по экономическим показателям
**Файл:** `4task2.ipynb`

Кластеризация стран (`Country-data.csv`) по социально-экономическим показателям (детская смертность, доход, экспорт/импорт, инфляция, продолжительность жизни и др.) для выявления групп стран со схожим уровнем развития.

- Масштабирование признаков (`StandardScaler`)
- Определение числа кластеров методом локтя (`KElbowVisualizer`)
- Сравнение алгоритмов: `KMeans`, `DBSCAN`, `HDBSCAN`, иерархическая кластеризация (дендрограмма)
- Оценка через Silhouette, Homogeneity, Completeness score относительно экспертной разметки (развитые / развивающиеся / прочие страны)

## 4. Классификация MNIST (Keras)
**Файл:** `5task1.ipynb`

Классификация рукописных цифр MNIST с постепенным усложнением архитектуры.

- Baseline: полносвязная сеть (Dense, tanh) — **accuracy ≈ 0.925** на тесте
- Улучшенная модель: CNN (Conv2D + MaxPooling) — **accuracy ≈ 0.992** на тесте

## 5. Кошки vs собаки (Keras CNN)
**Файл:** `5task2.ipynb`

Бинарная классификация изображений кошек и собак сверточной сетью на собственном датасете изображений (глубина — 5 сверточных блоков).

- Итог: **accuracy ≈ 0.67** на тесте (precision/recall для обоих классов ~0.65–0.70), модель заметно переобучается (train accuracy ~0.95 против val ~0.65-0.68)

## 7. Кошки vs собаки (PyTorch)
**Файл:** `6task2.ipynb`

Бинарная классификация кошек/собак на PyTorch, сравнение двух подходов:

- Собственная CNN (5 сверточных слоёв) — **test accuracy ≈ 54.7%**
- Feature extraction на замороженном MobileNetV2 + классификатор поверх фич — **test accuracy = 50.0%**

**Вывод:** на этом датасете обучение собственной CNN с нуля дало небольшое преимущество перед использованием признаков предобученной сети.

## 8. Классификация опухолей мозга по МРТ
**Файл:** `task3.ipynb`

Бинарная классификация снимков МРТ (наличие/отсутствие опухоли) с извлечением признаков через предобученный **MobileNetV2** (imagenet, без верхних слоёв) и сравнением классических классификаторов поверх полученных эмбеддингов.

| Модель | Accuracy | F1 |
|---|---|---|
| RandomForest | 0.89 | 0.89 |
| SGDClassifier | 0.95 | 0.95 |
| SVC | 0.92 | 0.92 |
| PyTorch (MLP-голова) | 0.95 | 0.95 |

**Лучшие результаты:** SGDClassifier и кастомная PyTorch MLP-голова — **accuracy/F1 = 0.95**.

## 9. Мультиклассовая классификация изображений
**Файл:** `task4.ipynb`

Классификация изображений на 10 сбалансированных классов (по 70 изображений на класс) с тем же подходом feature extraction через MobileNetV2 + классические классификаторы.

| Модель | Accuracy | F1 |
|---|---|---|
| RandomForest | 0.9857 | 0.9857 |
| SGDClassifier | 0.9857 | 0.9857 |
| SVC | 0.9857 | 0.9859 |

**Результат:** все три классификатора показали практически идентичное и очень высокое качество (**~98.6%**) — признаки MobileNetV2 хорошо линейно разделимы для этой задачи.
